# ไฮบัส (HIBUS)

เอกสารวันสาธิตโครงงาน STEM มัธยมศึกษาปีที่ 3 เรื่องรถโดยสารยกสูงประจำทาง และแอปวางแผนการเดินทาง

วันสาธิตมีสองส่วน

1. รถต้นแบบบน KidBright วิ่งตามเส้น ตัวรถยกสูง และหยุดเมื่อเซนเซอร์พบสัญลักษณ์ป้าย
2. แอปในโฟลเดอร์นี้ รู้ตำแหน่งผู้ใช้ รับชื่อปลายทาง แล้วบอกสาย ป้าย เวลาต่อรถ และค่าโดยสาร

ส่วนที่สองเป็นเมืองสาธิต ไม่ได้เชื่อมกับรถต้นแบบ เวลาอ้างอิงล็อกที่ 08:12 น. และตำแหน่งเริ่มที่หมู่บ้านสวนทอง เพื่อให้ตัวเลขบนเวทีเป็นชุดเดียวกันทุกครั้ง

## เปิดวันสาธิต

ต้องมีเบราว์เซอร์ ฟอนต์อยู่ในโฟลเดอร์ `fonts/` จึงเปิดได้โดยไม่ต้องต่ออินเทอร์เน็ต

```bash
python3 -m http.server 8741
```

แล้วเปิด [http://127.0.0.1:8741/](http://127.0.0.1:8741/)

- `infographic.html` ภาพรวม กติกา บทพูด และคำตอบถ้ากรรมการถาม
- `simulation.html` ตัวจำลอง กดสามปลายทางแล้วกดเริ่มนำทาง

แป้น `1` `2` `3` เลือกมหาวิทยาลัย ศูนย์การค้า และสนามกีฬา เมื่อไม่ได้พิมพ์อยู่ในช่องค้นหา

ปุ่ม «ลองออก 08:18» ใช้เมื่ออยากให้เห็นว่าระบบจับรอบรถใหม่ ถ้าผู้ใช้ออกเดินช้า

## ตรวจตัวเลข

```bash
node network.test.js
```

## ชื่อที่ใช้ในชุดสาธิต

ชื่อไฮบัส เมืองสาธิต และสามปลายทางตั้งไว้เพื่อการนำเสนอ เปลี่ยนถ้อยคำใน `network.js` ได้ที่ `PRODUCT` และ `places` แล้วรันเทสต์อีกครั้ง
