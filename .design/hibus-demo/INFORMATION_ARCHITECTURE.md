# Information Architecture: HIBUS demo

## Site Map

- ทางเข้า `/` หรือ `index.html`
  - ภาพรวมโครงงาน `infographic.html`
  - จำลองแอป `simulation.html`
    - สถานะค้นหา
    - สถานะผลลัพธ์
    - สถานะนำทาง
    - สถานะถึงแล้ว

## Navigation Model

- **Primary navigation**: ภาพรวม และจำลองแอป ไม่เกินสองปลายทาง
- **Secondary navigation**: ในจำลอง เป็นปุ่มปลายทางสามปุ่มและปุ่มนำทาง ไม่มีเมนูซ้อน
- **Utility navigation**: สลับธีม และลิงก์กลับทางเข้า
- **Mobile navigation**: ลิงก์เรียงเป็นแถบเต็มความกว้าง ไม่ใช้เมนูแฮมเบอร์เกอร์

## Content Hierarchy

### ทางเข้า
1. ชื่อโครงงานและคำอธิบายหนึ่งย่อหน้า
2. ทางไปภาพรวม
3. ทางไปตัวจำลอง

### ภาพรวม
1. ภาพตัดรถยกสูงกับคำจำกัดความ
2. ลำดับสามขั้นบนเวที
3. สิ่งที่รถ KidBright ต้องทำให้เห็น
4. แผนผังสามสาย
5. กติกาหกข้อ
6. ลำดับ UX
7. ตัวเลขสามปลายทาง
8. บทพูดและคำถามที่พบบ่อย

### จำลองแอป
1. ตำแหน่งปัจจุบันและนาฬิกา
2. ช่องปลายทาง
3. แผนที่เลือก พร้อมเวลา ราคา และเหตุผล
4. แผนผังที่จุดผู้ใช้และรถขยับ
5. ตัวควบคุมเล่น หยุด และขั้นถัดไป

## User Flows

### ต่อเดียว
1. ผู้ใช้เปิดจำลอง
2. เห็นหมู่บ้านสวนทองและรอบ H2
3. เลือกมหาวิทยาลัย
4. ได้แผนสายเดียว ถึง 08:37
5. กดเริ่มนำทางจนถึงประตู

### ต่อมากกว่าหนึ่งครั้ง
1. เลือกศูนย์การค้าหรือสนามกีฬา
2. ระบบเทียบกับแผนเดินไปขึ้นสายหลักเลย
3. แสดงป้ายขึ้นแรก รอบที่ทัน จุดลง และทางเปลี่ยนชานชาลา
4. ระหว่างนำทาง ข้อความเปลี่ยนตามช่วงจนถึงปลายทาง

### ออกเดินช้า
1. อยู่ที่ผลลัพธ์
2. กดลองออก 08:18
3. รอบที่ทันและเวลาถึงเปลี่ยน โดยตำแหน่งบ้านเดิม

### ปลายทางนอกเมืองสาธิต
1. พิมพ์ชื่อที่ไม่มีในชุด
2. ระบบบอกว่าไม่พบ และยังแสดงสามปุ่มสาธิต

## Naming Conventions

| Concept | Label in UI | Notes |
|---------|-------------|-------|
| Product | ไฮบัส / HIBUS | ชื่อชุดสาธิต |
| Fixed stop | ป้าย | ไม่ใช้คำว่าจุดรับ |
| Platform change | เปลี่ยนชานชาลา | การต่อรถคือการเดิน |
| One vehicle | ต่อเดียว | ถึงหรือเกือบถึง |
| Transfer | หนึ่งต่อ / สองต่อ | นับจำนวนครั้งที่เปลี่ยนสาย |
| Fare flagfall | ค่าแรกเข้า | คิดครั้งเดียวทั้งทริป |
| Demo clock | เวลาอ้างอิง | 08:12 น. |

## Component Reuse Map

| Component | Used on | Behavior differences |
|-----------|---------|---------------------|
| Header | ทุกหน้า | หน้าปัจจุบันมี aria-current |
| Transit map | ภาพรวมและจำลอง | จำลองอัปเดตตำแหน่งรถและผู้ใช้ |
| Theme toggle | ทุกหน้า | จำค่าใน localStorage |
| Place chips | จำลอง | สามปลายทางจากข้อมูลชุดเดียวกันกับภาพรวม |

## Content Growth Plan

ชุดสาธิตมีสามปลายทางคงที่ ถ้าเพิ่มสายหรือป้าย ให้เพิ่มใน `network.js` แล้วให้ทั้งแผนผังและตัวเลขบนภาพรวมอ่านจากที่เดียวกัน

## URL Strategy

- ไฟล์ตรง ๆ ไม่มีเราเตอร์: `index.html`, `infographic.html`, `simulation.html`
- ไม่ใช้ควารีพารามิเตอร์ ปลายทางที่เลือกอยู่เป็นสถานะในหน้า
