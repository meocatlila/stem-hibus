# การตัดสินใจออกแบบรถต้นแบบไฮบัส

อัปเดตจากการสัมภาษณ์ออกแบบ — ใช้คู่กับ [HIBUS_VEHICLE_RESEARCH.md](./HIBUS_VEHICLE_RESEARCH.md) และแผนรวมใน [HIBUS_VEHICLE_PLAN.md](./HIBUS_VEHICLE_PLAN.md)

## ล็อกแล้ว

| หัวข้อ | การตัดสินใจ |
| --- | --- |
| จุดขายวันสาธิต | ตามเส้น + หยุดป้าย **และ** ตัวถังยกสูง ต้องเห็นชัดทั้งคู่ |
| เครื่องหมายป้าย | เทปดำ (เช่น เทปพันสายไฟ) **คาดขวาง** บนเทปดำเส้นทาง — จุดคาด = bus stop |
| พฤติกรรมหยุด | หยุดนิ่งจนกว่าจะ**กดปุ่มบน KidBright** แล้วจึงเดินหน้าต่อ |
| ตัวถัง | ฐานชุด KB Robot + ตัวถังโฟมบอร์ด/กระดาษแข็งยกสูง (ช่องลอดใต้ท้อง) |
| สนามสาธิต | สายเดียว (วงรี/เส้นปิด) มีป้าย 2–3 จุด — ไม่ทำหลายสายในรอบแรก |

## นัยต่อโปรแกรม

1. โหมดตามเส้นด้วย IR ซ้าย–ขวา  
2. เมื่อเซนเซอร์สองตัวอ่านดำพร้อมกันแบบแถบคาด → เข้าโหมด STOP_WAIT (มอเตอร์หยุด)  
3. รอเหตุการณ์ปุ่มบนบอร์ด  
4. คืบตรงออกจากแถบคาด (LEAVE_MARK) แล้วกลับโหมดตามเส้น  
5. ตัวถังยกสูงเป็นงานโครงสร้าง ไม่ผูกกับเซนเซอร์ป้าย
